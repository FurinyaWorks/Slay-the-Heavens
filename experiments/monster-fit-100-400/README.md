## 固定变量与结果

完整原图以 contain 缩至 94×94、居中放入 106×106（每侧6px），遵循既有源审建议。每份原图穷举4..64方格，复用既有颜色量化、alpha>=8筛选、同色行段/纵向合并。每个预算选择 premultiplied RGBA MAE 最小的结果；不假设图元数随grid单调。隐藏RGB不参与透明区误差。这个分数只解释误差，不授予视觉通过。
