# 净化神龛与金翼雕像：定额精修

在 48 个图片控件 + 1 个根容器不变的前提下，手工补回净化神龛凹下去的发光石盆与空中橙色神龛，金翼雕像补回三颗金色奖励并保留双层蓝翼读形。独审选择两张新版作为离线预览；石龛的火焰光晕、细纹和部分骨架仍简化，金翼下方第二组金币与部分洞窟细节仍缺失。尚未过正式美术验收。
