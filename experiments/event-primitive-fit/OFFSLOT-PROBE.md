# 七张事件拟合：方框与底板实测

用 BeyondSimulator 0.5.2 在固定 1280×720 画布渲染 7 个 49 控件候选。在当前 develop `c186c1dc` 官方样式坐标放置拟合（中心 −372、−50），每张只切换拟合根容器可见性，同一帧各截图两次，要求相同字节且无画面素材警告。全图做精确像素差分；不把裁剪后预览当源画面。测试使用单独实验场景，不是游戏场景。

- 七张都超出名义 330×330 方框，41–467 个可见像素；鎏金石龛面积最多，黏液金币最远（向左 16 px）。
- 7/7 都没有超出 410×410 底板的几何范围；这是普通屏幕坐标的覆盖判断，**不是底板有裁剪属性**。
- 普通事件标题、正文与选项区域没有重合像素。官方资源样式的返回、确认框也没有重合；普通事件本来就隐藏这两个通用按钮，结果页保留图时只显示右侧「继续」。另一个 V25 样式的左侧返回框几何上有潜在重合，不能拿它代表官方资源样式，也还未做该样式的运行时点击测试。手机、旧 180×180 事件布局、真实事件切换与实机均未测。
- 不建议靠更少控件或更小的整体缩放来解决这个问题。生产接入前，在真正事件状态确认底板可作为边界、各样式返回/确认层级以及切换复位；若设计要求插画不超出 330，需验证实际裁剪或限定形状边界。

```sh
EVENT_SLOT_POSITION=1 node offslot-probe.mjs "$REPO" selected offslot-exact
python slot-diff.py offslot-exact 268 410
```
