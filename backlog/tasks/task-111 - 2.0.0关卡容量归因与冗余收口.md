## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**本次 v2.0.0 Release 容量专项，允许立即独立开展，不等待 TASK-103 或全部产品/UI 完成人工验收；硬依赖为空。** 在保留岩系旅行者、前两幕、已批准视觉/功能、规则与交互的前提下，定位关卡存档反复逼近/超过官方 20MB 上限的真实主要成本，并按收益完成必要的最小冗余收口。发版前必须有**最终同一候选**的官方容量通过证据。

历史证据分别是 70.51413MB/20MB 的 V25 静态展开失败、旧 8.96MB 基线、其他 19.78MB 可导入候选及 Owner 的 20.1781MB 超限截图；**彼此未绑定同一候选身份，不得直接相减、伪造增长曲线或归因占比**。源码/GIL 文件大小、Git pack、模拟器控件数均不等于官方存档读数。16MB 是争取的内部余量目标，不是替代官方的硬限制。

**与已有任务划界：** TASK-10.1.2 负责卡图/多实例与手机专项；TASK-100 负责运行时性能热路径；TASK-105 仍属 M9 新增角色边际成本及 10/20/30 角色量产准入，TASK-97 仍依赖 TASK-105。本任务只负责当前 2.0.0 整包容量归因、可证明的冗余修复与防复发；引用上述任务但不要求它们先完成，也不接管未来角色量产。
