# v2.2.0 事件与卡牌详情预览

正式发布基线为 `95b003d41a229218916d20785145cd4a7e9583fe`，实测生产源码前缀为 `01863013`。本轮采用现行正式共享卡面。误用的 V25 实验回放稿已在设计索引标为 `REJECTED`。[现行卡面登记](../../design/reference-assets/v2.2.0/card-face-20261128/REFERENCE.md) · [设计索引](../../design/UI_REFERENCES.md)

- 巢穴整按钮即时预览真实仪式匕首。牌名显示一次，收益、牌名和代价分别按原版色义显示。固定事件对象的诅咒及遗物共用预览。禁用选项可以显示原版绑定的详情，执行仍受既有条件限制。
- 幻影升级前后的说明由各自生效的卡牌定义产生。桌面悬浮严格超过 0.2 秒时显示，离开热区关闭。适用的商店、牌组、牌堆与选牌入口恢复关键词预览。战斗和奖励卡牌的既有详情位置保留，桌面计时与原版对齐。
- 移动模拟沿用项目的 0.35 秒阈值。事件在松手后保留卡面，离开热区或下一次按下关闭。锻造保留到从现有详情返回。战斗选牌沿用手牌查看的松手关闭。长按消费相应点击。

## 验证摘要

- Beyond Simulator 0.5.2 完成 16:9、21:9、19.5:9、4:3 四个视口的 140 项检查和 64 张原始截图。核对了文案颜色、0.2 与 0.35 秒边界、快速切换、松手与取消、卡面与关键词完整可读、实际确认与取消目标及 Run、牌组、资源与 RNG 不变。
- 锻造中两组升级前后卡面及两个按钮的 8 个无预览截面像素完全一致。实际光栅通过巢穴正文、锻造关键词及商店末行检查，保留旧候选只显示 1/2 行的负控。[像素与回放清单](simulator-manifest.json)
- 正式源码生成布局含模板由 26,338 个控件增至 26,665 个，最大直接子项仍为 60。新增控件含一张共用事件卡面和被动说明层。各场景空闲帧无重复控件提交，销毁时无控件残留。官方存档容量与设备负载按冻结候选实测。

同一正式 GIL 的官方编辑器导入、启动、容量与实体手机的长按、松手、取消、设备安全区和误触仍待验收。正式封板沿用当前发布门禁。
