# 2.0.0 默认菜单：标题补位可行性，设置入口分开查

## PC01 主菜单标题

[结构试验](PC01-PROTOTYPE.md)复用了 #699 的精确批准稿标题标记，确认默认布局缺该标记。仅在内存树插入，原「开始 / 继续 / 退出」、命令、触点和结算节点全部保持，撤掉插入后整树与此前相同。新增 **397 图元＋19 容器**，尚未确认容量、真实画面或菜单状态切换，不能直接照搬成正式改动或称 PC01 完成。建议 #699 如确需本版标题就只提取静态标题，在默认菜单显隐中与旧文案互斥；不要迁移整套预览按钮或背景。默认原拟合主体和导航不因美术交付改变。

## PC06 / 手机设置入口

对[上一轮产品组合](../default-build-and-player-smoke/DEFAULT-BUILD-AND-PLAYER-SMOKE.md)的真实默认生成布局，原设置入口位于逻辑坐标 `[576,316]`，48×48 点击区，距逻辑画布右侧 40、顶部 20；四态仍有三条 14×1 原生图元，非字体齿轮。实际 Host 分别按 PC、手机横屏尺寸和触屏标志模拟，主菜单、地图、战斗三处均可从入口打开暂停并恢复同一局，软件模拟中没有完全消失或被默认画布裁掉。[布局哈希与四态](default-menu-geometry.json) · [Host 探针](default-menu-host.lua) · [结果](default-menu-host.log)。

这**不能排除**玩家手机在真实 UI、缩放、色彩或叠层下看不到线条。一逻辑像素高的线本身也不是视觉可读性合格的证据。首轮真机按短程方法先判：最终正式候选到底绘制三线还是齿轮，在选角/地图/战斗何处不可见，以及按下前后是否漏某一状态。关联同一构建 ID、设备方向、画面与日志；别把 #695 的 experimental 齿轮绿灯当成正式默认问题已修。本轮无额外 Full、SDK、用户机器、在途 PR 变更。
