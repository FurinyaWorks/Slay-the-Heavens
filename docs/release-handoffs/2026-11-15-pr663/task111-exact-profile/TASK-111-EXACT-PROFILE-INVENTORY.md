## 有界单因素：V4

从同一生成集只在离线部署映射排除 `abyss_original_v4_data`，366→365、少 **577,904 原始字节**；其余 SHA 完全一致。公开 Geo 选择及实际 GameUI mock 子集两侧 PASS 且输出相同，但不受限的开发角色 prepare 立刻因缺模块失败。使用本配置的原原生入口测试两侧都受未绑定立绘与 mock 缺 `SetActive` 限制，未宣称通过。[对照](v4/EXPERIMENT.md) · [摘要](v4/omit-summary.json)。不直接改生产白名单，不破坏全源开发模式。
