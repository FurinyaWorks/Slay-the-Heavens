## 复现

以 `REPO` 指向上述精确 Release checkout（项目已有 Node 依赖、SHA 匹配的人物预览图 LFS），在此目录执行：

```sh
python acid-medium/build.py "$REPO" ../monsters/slime-44
node qualify.mjs "$REPO" acid-medium/native-layout.json matrix.json
ACID_MEDIUM_LAYOUT="$PWD/acid-medium/native-layout.json" RELEASE_REPO="$REPO" node run-stock-pilot.mjs
```

[`../monsters/slime-44`](../monsters/slime-44/) 是原面向 44 控件验收的色面数据；复用 [第二批](../monster-pilot-02/README.md) 无掩码原生行和强校验适配器。Lua 模板字节比较只对本离线序列化生效，不推断 GIL 或官方服务器读数。
