# 两类技术锚点
- 草史莱姆 44 与遗迹守卫 119 已获造型认可；这一决定覆盖历史结果中当时的“待认”。36/110 为过度压缩反例，不做默认素材。
- 作者选区/形状记录在 slime-44、ruin-119。冻结的最终原生数组、实际 mock 脚本及结果不重复复制，直接引用 [R5](../../r5/README.md)；低档结果见 [R6](../../r6/README.md)。
- slime-44 可从 Python 重建中间设计；在本地的归档副本运行 python slime-44/flat.py /path/to/game-repo，再执行 python slime-44/encode.py。其三角化函数来自同档案下的 history/fit200/fit.py。
- ruin-119 的 refine120.py 是曲面精修过程脚本；R5 的 native-layout-whole-119.json 是用最终手工调整后冻结的数组，以它及其 probe 为准，不声称仅运行该过程脚本就一定得到同一文件。
- 这些 PNG 是拟合重建预览，不接正式怪物池。按资产真实容量而非选前全目录上限分配，是后续生产接入验收项。
