## 如何复用

- 先读 [角色生产规范](../../../../design/characters/PRODUCTION.md)、[角色美术提示词](../../../../design/GEO_LUMINE_RENDERABLE_ART_PROMPT_20261113.md) 与 [仓库原生图元试验](../../../../plans/2026-11-13-lumine-native-fit.md)。画法为 clean cel-shaded low-poly / flat-shaded polygons anime：大面积平涂、清楚剪影、极少渐变。不新建另一套实际运行时。
- 项目当前背景的配准、色面、原生形状放置及遮罩分片经验可复用。人物把预算优先给脸、眼、发饰和轮廓，身体/武器按重要性精简。预算按实际创建的图元＋容器统计；不要用单纯形状数、GIF 帧数或脚本大小充当控件数。
- 动作和绘图分开，持剑手和剑保持同一所有者；切屏、着色、死亡、释放、同屏多个实例用已有的测试机制。单只独立 mock 不证明生产容量、正式美术可发布、设备帧率或温度。
- 本目录保留项目本轮输入、产出和实验。源图身份以 SHA 区分，不推断第三方版权或平台发布许可。SHA256SUMS 用于确认本目录归档的确切字节。
