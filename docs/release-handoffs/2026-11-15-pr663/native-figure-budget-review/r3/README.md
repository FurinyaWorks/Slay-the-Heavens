# 固定预算内先精修，再二分

用户确认：草史莱姆85、遗迹守卫198为已认可外观，旧稿原样保留。荧360仍粗糙，尤其脸，180与360均不采用。当前都是独立绘图方案，未接游戏、没有真机性能或官方容量结论。

各档先定控件预算（图元与容器皆计），第一稿不足只标待修，不立刻调整区间。在同一预算里合并次要色块、把图元补给剪影/识别点，再用相同战斗尺寸重看。只有同档优化后仍达不到门槛，才上调；通过后才试更低档。各任务样本不同，未宣称经验最低值。60/30/10作为角色资源分配试案，不是玩家注视统计或硬门槛。

| 对象 | 同档迭代 | 离线可复现结果 |
|---|---|---|
| 草史莱姆 | 85保留。低档67首稿身体过平，保持67并把斑点图元换成身体大亮面。中间76也留档。 | 67=63图元+4容器，低档待审。 |
| 遗迹守卫 | 198保留，114是明显失去体积的低锚，不是优化穷尽。中点156首稿152，固定上限把少量内饰配额补回双肩甲和橙带。 | 155=150图元+5容器，低档待审；171为更保守档。 |
| 荧头部 | 整体为360的前稿不采用，只重做头部。固定111预算，首轮111；第二轮用椭圆做圆润花瓣与眼反光，把部分预算还给后发弧线和蓝色系带。 | 107=103图元+4容器，只审脸部与发型，不是整人计数。 |

这三组都在同一基线仓库原生控制器 mock 验证建立、120次静态pose、无图元改写或重建、回访缓存及释放归零。静态pose不代表受击/淡出。独立运行脚本在仓库根调用，各自数据同目录。外观低档未获用户确认，不改生产怪物池。定义可重用、镜像可少做形状定义，但同屏实例的坐标、血条、受击状态必须独立。
