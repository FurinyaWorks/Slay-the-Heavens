怪物共用池问题：当前默认 monsters=false；显式打开后，先按整个保留目录取 max=600，再应用只包含草史莱姆的 candidateAssets 白名单。整个 actor 模板为647控件（不含单独 power 模板），即使草史莱姆数据已经降到120也不会自动减池。遗迹守卫虽有绑定，但不在当前白名单内。统一应先做到「选中资产决定容量，或每实例按资源分档」，不能按一张低图元 PNG 推断成包或真机收益。

统一建议：语义大色面、少量可识别细节、合并连通轮廓后用已有原生三角放置和合法蒙版，静止图元只配置一次；每个动画组保留真实父级和锚点。分别计图元、实际容器、预分配总池、待机与动作写入、释放；保持设备/GIL门禁。荧和史莱姆各自的独立 mock 数据与脚本可在项目根运行 node /path/to/runtime-probe.mjs。
