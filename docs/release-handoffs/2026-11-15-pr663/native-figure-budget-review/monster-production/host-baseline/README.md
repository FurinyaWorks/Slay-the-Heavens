第一版将六只冷首次更新和稳态混在一起，零写断言失败；分开后保留两种证据。真实非致死 strike（6 HP）、致死命中、原始死亡状态与最后关闭、六个重复/混合实例、失败回退全部原断言通过。运行期只有 enabled 怪物子树挂计数；访问和同值写入分别统计，断言读回和 setup 不计。#706 官方配置原有粒子回放不包含这一套美术；它的观察器也不包含 GetChild 或 GetChildren。

每次真正改变色调按原代码遍历已使用图元，597槽的一个淡出样本为597写与1+2×597读取。同值 RGBA 仅占本次受击1.25%、动作期间淡出4.27%；不建议优先单独做逐槽颜色缓存。量产优先绑定已经更少图元的资源并按实际候选/实例控制容量；之后对正式的受击/淡出、同时有多个活跃实例的独立回归。不得把低控件局部绘图数替代全actor、真机热量或官方容量。

复现：在精确仓库根先生成 build/formal 的数据（见既有 TASK-111 固定生成回执），再 node 路径/run.mjs。脚本生成明确开启 monsters 的 test UI，在外部目录注入计数，项目源不写回。--reuse-generated 只用于同一 workspace 的一次相同 fixture 重测。reports/counts 的 source hash 与目录回执绑定。
