# 正式战斗 UI

## v2.0.0 怪物说明

电脑悬停怪物本体、头顶意图或血条，三处均打开同一组紧凑提示。手机点按打开，点空地关闭。牌或药水拖拽期间不打开提示，目标提交沿用既有输入优先级。本节取代《UI 设计规范》早期的怪物意图打开方式，以及 #897、#919 的逐效果说明。

- 按 STS1 的 `AbstractMonster.updateIntentTip` 和 `renderTip`，第一项显示当前意图的类型和完整正文。攻击沿用头顶当前的每段伤害预览。多段攻击在头顶显示伤害和次数。纯攻击、攻击强化及攻击防御可在说明中写次数，攻击削弱只写每段伤害。强化、防御、削弱及其复合意图说明行动类别。已有 Power 各占一框，显示其层数、持续时间和机制。符文圆顶仅隐藏意图。
- 意图与 Power 使用同一种左对齐文本框。计算容量时跳过颜色标签，保留显式换行并计入宽度引起的折行。每行预留现有的 40 设计单位兼容预算，背景和列间排列随内容高度变化。多列超过安全宽度时保留 18 号字。手机点页码翻页。电脑点击当前悬停区域固定后可点页码，目标输入优先。预算来源见 [原生文本高度兼容记录](../art/CARD_TEXT_HEIGHT_COMPAT.md)。
- 官方 `enemyIntentTooltip` 验收在同一候选的 PC 和手机记录源码 SHA、构建收据及载荷、怪物和招式 ID，以及 `copy` 的文字、尺寸、字号与最小字号、缩放、对齐、显隐和前后截图。覆盖无 Power 的攻击与纯强化、大颚虫三招、多段伤害随 Power 更新、三处悬停与快速切换、圆顶、窄屏长列表与翻页、拖牌及拖药水优先级。高度单变量对照也须保存官方客户端前后截图。当前候选的官方设备验收待完成，已有 Host 与生成控件回归。

## 2026-10-28 对照记录

本次以根工作树 `b6fb0f4a` 的 ui-canvas 八稿为对照，生产实现从 `origin/develop d2e0baa3` 隔离修改。共享卡框、游戏规则、数值和地图未改。

| 设计稿 | 本次实现与复用 | 验证边界 |
|---|---|---|
| Main | 顶栏钢条、金线及标题两侧饰线；晶核多面体叠层；结束回合剑形饰件；玩家左侧、敌人右侧，拥挤时交替两排 | 原生图元替代 CSS 渐变、阴影和模糊；不是浏览器效果原样移植 |
| TargetState | 保留药水目标绑定、空白取消、失效输入隔离；圆槽展示真实药水图库图标，名称/效果及独立详情入口保留 | 药水待选阶段仍标亮所有合法目标，不假称已锁定某个敌人 |
| CardAimState | 复用14星点、拖回取消和触摸偏移；选中敌人新增四角框；拖牌锁定后其他立绘40%透明度 | 点选 C 档继续标亮合法目标；不会替玩家猜目标 |
| StatusState | 复用单位→生命/格挡→增益/减益→效果/条件的详情与分页；详情跟随新站位并限制在安全区 | 保留分页替代滚动，全部条目可达；真实字体及触摸需实测 |
| PotionState / Potions | 保留真实药水效果文本、目标策略、说明及使用/取消流程；圆形瓶图入口复用已有说明动作 | 稿内药水数值不参与运行；真实效果仍来自核心目录 |
| CrowdState | 生产合法最多五敌全部保留核心索引，右半场双排；血条/格挡、意图、命中、反馈和详情使用同一槽位坐标 | 六敌稿不改变现有五敌容量或遭遇内容；无六敌生产验收声明 |
| Spec | 多段/复合意图沿用真实规则显示；拥挤时数字在图标下方；三位格挡与原生行高保留；状态溢出和详情分页复用 | 自制 SVG 图标、圆角及发光的完整视觉一致性仍需正式素材/实机审查 |

伤害预演在完整隔离副本调用真实 `Combat.play`，读取相同敌人 ID 的结算后生命；原始状态（含事件、随机流）不写入。选择尚未完成、命令无效或核心调用失败时不显示扣血或击杀。普通牌面仍复用 `Combat.cardPreview`，不从牌面文字计算扣血。预演只在有效拖牌目标/投放区域出现，取消后恢复实际血条。

本轮采用可运行的原生圆片、菱形、线条和图库图标作为渐变、晶核和剑形替代。截图生成器使用原型字形替代图库，不能用这些图证明官方素材语义、原生字体或设备性能；同候选客户端和实体手机验收仍未进行，`verify:ui <候选.gil>` 仍是正式 UI 验收门禁。
