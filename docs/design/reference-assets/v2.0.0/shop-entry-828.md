# v2.0.0 商店房间与商品页

入口在共享 HUD 下展示有纵深的石柱、暖光、石地和商摊。商人完整坐在画面右下的地毯上，身边有货物。点击商人或「查看商品」展开货架，入口也保留独立的离开操作。项目按璃月题材重新制作场景，使用已有的千星图库和原生图元。 [原版房间参考](https://www.gamersdecide.com/sites/default/files/authors/u159207/slay-the-spire-merchant.jpg)

展开后，商品铺在布面上。上排五张牌，下排左侧两张无色牌，中间两排遗物与药水，右侧删牌服务，每项的价格紧贴商品。离开按钮留在左下方。商人只在房间出现，交易反馈短时显示。 [原版购物参考](https://minireview.io/common/uploads/review/70b4d52f5141a845b9c094921abcda8e.jpg) · [Issue #828](https://github.com/FurinyaWorks/Slay-the-Heavens/issues/828)
