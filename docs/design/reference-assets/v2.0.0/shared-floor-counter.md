# 局内顶栏楼层计数

参照 Mega Crit 2024 年 11 月 7 日发布的《杀戮尖塔2》“Top Bar Changes”。原图中药水栏右侧依次是房间图标、三级楼梯和独立数字 8。此处采用楼梯加数字的读法，在现有药水栏右侧用三个矩形绘制简化楼梯，数字沿用项目顶栏字号。 [官方说明](https://www.megacrit.com/news/2024-11-07-neowsletter-issue-4/) · [官方顶栏原图](https://clan.fastly.steamstatic.com/images/29087962/f64659057481ec143821677630897786ec4a6b9e.jpg)

祝福、普通房间、地图和战斗共用同一外观，数字各自读取当前楼层。开局祝福显示 0，进入第一场战斗显示 1。房间名称继续由各自页面正文呈现。这个图标沿用项目现有矩形材质，不引入独立纹理或输入控件。
