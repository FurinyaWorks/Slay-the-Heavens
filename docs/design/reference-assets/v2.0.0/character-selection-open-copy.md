# v2.0.0 选角信息直接排在背景上

Owner 根据初代《杀戮尖塔》的观者及战士选角截图纠正了设计目标。生命、金币、角色介绍、初始遗物和已有的初始牌组摘要直接排在左侧，角色脸部无遮挡。文字用原生描边保持清晰，岩脉残晶旁放置小型原生岩晶图标。选角页移除「查看牌组」入口。角色画面使用项目已批准的 1600 图元原生背景，保留调好的选角槽和返回、出发四态按钮。

一代战士选角的公开画面可直接核对信息与角色图的叠放关系。观者截图用于同样的构图对照。[初代《杀戮尖塔》选角](https://interfaceingame.com/screenshots/slay-the-spire-choose-your-character/)
