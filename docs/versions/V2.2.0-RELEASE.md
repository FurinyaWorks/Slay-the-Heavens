UI 参考的版本、有效性、被替代稿和实施点统一登记在 [UI 参考索引](../design/UI_REFERENCES.md)。未验证宿主能力和实渲前，响应式、两幕构图、脚底锚点和透明度修复均待形成 v2.2.0 可实施稿。每项新稿需要包含适用版本、源图和实际截图坐标、现行稿、被替代稿、关联任务/PR 和验收场景。已有选角原参考和废弃原型的历史记录沿用该索引，接续 #924 后按实际审定结果更新。
