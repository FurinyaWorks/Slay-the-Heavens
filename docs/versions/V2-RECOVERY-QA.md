# v2.0.0 PC 与手机回归清单

本清单补充正式候选复验。以下 58 条的本轮设备结果均为待验。保留原始时间码、截图和风险判定，以源清单和任务的有效验收条件为准。

同一候选登记源码 SHA、构建参数、buildId、GIL SHA-256、payloadDigest、平台版本、设备与时间。先完成官方导入和 ready，再分别记录 PC 鼠标键盘、实体手机从主菜单到两幕结算。覆盖新开与续局、祝福、地图、战斗、药水/遗物、奖励、商店、营地、事件、首领、跨幕状态、胜败与退回主菜单，并记录官方关卡和服务器容量。准备和卡顿问题留时间线、触控轨迹或帧耗。

现有检查和原始复现见 [重建路线图](V2-RECOVERY.md)。
