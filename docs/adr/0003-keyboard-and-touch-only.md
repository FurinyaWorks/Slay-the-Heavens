# 0003 当前版本的输入设备范围

## 背景

2026-11-22，Owner 确认目前无法取得手柄设备来验收完整游玩路径，要求在项目全局移除尚未完成的手柄支持。Release 的 #897 在发布入口关闭了手柄，本次收口同时覆盖 Develop 的各页面和原生模板。

## 决策

键鼠和触屏是当前支持的输入。删除手柄启动接口、导航监听与焦点状态、地图手柄翻页按钮和玩家手柄提示。正式构建和开发构建采用同一输入范围。连接手柄的手机仍按触屏设备处理，其触摸输入照常工作。

牌库继续使用上一页、下一页按钮和键盘左右键。输入盖板与指针按下、抬起和点击的身份仍分别验证。发布验证覆盖键鼠和触屏两条完整路径。

## 恢复条件

历史实现保留在 Git 历史中。将来若重新纳入手柄，需要另行取得 Owner 确认和设备，验证菜单、地图、战斗、奖励、选择、详情及取消的完整流程。
