用现有原生图元生产工具链对这套 **角色本体** 做一次可复现的低控件拟合/手工简化技术打样。不要生成新角色、改官方身份、换姿势、创造武器、画场景、怪物、UI、血条或背景；不重做当前游戏接口或卡牌。优先以荧做一个完整的小样，质量与成本合格再试跨体型角色，并比较可复用性。
