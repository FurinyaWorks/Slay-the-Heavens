## 批量步骤

1. 先锁原图、裁片和剪影，不能改姿态或按不同轴缩放。用项目现有原生摆放与三角剖分先处理大色块，随后手修两眼和细武器。芙宁娜用自动色面加帽饰、眼、细剑和腰扣的局部描线；钟离用大色面描原稿并保留枪头镂空。
2. 优先审 133×133 原尺寸，再放大查问题，深/浅两种底色用同图对照。首批可辨识；芙宁娜脸颊残留颗粒，钟离枪头边缘与眼形仍有差距，不是量产美术批准。
3. 500 是本次试样预算，不是平台容量。每组最多 60 图元，加角色宿主/界面根；不加纹理、蒙版、背景、文字。日后接共享战斗运行时，要另查待机逐图元重建与写入、页面回访销毁和同候选的 PC/手机验证。

## 重放

每个子目录的 `editable.json` 是冻结的原生几何参数（仅去除 JSON 空白），可直接导入同版本 Image Editor。参考裁框及参数统计见 `verification.json`；同时内附原始导出哈希、GIL 回读及 Lua 模拟收据。使用 `replay.py` 重放，校验 PNG 和 Lua 原生数据；沿用 [荧试样](../lumine) 的 `export-batches → prepare-base → pack → check-lifecycle`。夹具脚本里的 Lumine 名称是历史内部标识，各包为独立文件。沿用同级的原生 Lua 许可证标注。
