# 芙宁娜 R6：原稿轮廓重拟合（离线候选）

继 R5 小尺寸观感仍不合格，改用[原生怪物量产](../../../../../../../docs/art/NATIVE_MONSTER_PRODUCTION.md)的「先连续剪影、再材质明暗」顺序。按用户提供的同一参考图描刘海、下颌和帽饰留白；身体裙摆、腿及长剑也按同一原稿重做。借鉴背景流程保持同一缩放参考、分开校验编辑器源场景和实际 Lua。原姿势、武器方向不变；角色左眼深蓝、右眼青蓝。上眼线只改透明度，未加入贴图、背景、滤镜或新运行模块。

像素对照直接渲染 64–133 像素的原生形状，另测半像素偏移，检查深浅两种底色；不是游戏截图。96/133 的帽饰、刘海和剑轮廓比 R5 更容易分辨；64 的两眼仍有挤在一起的风险，整幅图同零偏移的深背景距原稿误差 19.61→20.32，未承诺最小尺寸达标。几何修正而非仅提高预算：优化掉身体十片小形状，帽饰保留一条连续卷发轮廓，厚眼线收薄。测量不等于美术批准。

573 个原生图元，10 分组＋1 宿主＋1 根，共 **585** 个绘图控件。161,165 字节的是离线图元夹具，不是发布包。两次同输入构建字节一致；573 个 Lua 图元全部核对类型、位置、尺寸、旋转、锚点、顺序及 RGBA，创建、清理与故障后重建测试通过。未导入游戏，未测设备、帧率或战斗峰值，未接入 develop 或 Release。

## 重放

以 [R5 small-display](../small-display) 重放出的 editable 为输入，执行 `python replay-delta.py R5/editable.json R6/editable.json`。复制本目录 `verification.json` 至新 editable 同级，沿用 [Batch 01 replay.py](../../replay.py) 和相同的固定 Image Editor 导出 PNG 和原生 Lua。全量输出图元顺序、可重放几何、原稿指纹/裁切、颜色校准参数、实际夹具读回与离线测试见本目录。仓库不含用户上传的原稿，也不上传夹具副本。
