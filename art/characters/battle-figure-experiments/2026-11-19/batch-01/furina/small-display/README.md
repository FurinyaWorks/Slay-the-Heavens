# 芙宁娜：64–133 像素原生小尺寸版

用户指出缩小后不合格，按同一原稿、实际 64／96／133 像素直接渲染判断，另采样数个尺寸以避免只优化一档。对原稿删掉经多尺寸比较造成亮点、裙边和细剑断裂的细碎图元，以相连大色面为主；根据原稿同尺寸采样校正衣边、帽饰、细剑等过硬的亮度与少量透明度。原姿态、构图与两侧虹膜身份保留（角色左深蓝、右浅蓝）。不引入位图、模糊滤镜或客户端改动。

所选 320 个原生图元＋6 分组＋1 宿主＋1 根＝328 控件（上版 499）。同一深色背景上，按原稿可见区域计算的 RGB 平均误差：64 像素 31.19→20.33，96 像素 26.43→19.94，133 像素 22.77→19.19；这是离线辅助读数，不等于观感评级。两枚浅透原生椭圆代替八段眼线，64 像素仍不足以清楚显示眼睛细节，未实测手机／PC 或游戏内缩放。离线夹具 GIL 104,140 B，两次导出和试包一致，320 个图元的实际 Lua 清理、重建和失败恢复通过既有 mock。
